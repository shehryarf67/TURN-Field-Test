TURN: five UI directions

Each file shows the same journey (Explore → start → destination → facing → live navigation → buildings or setup) on the real C-F4 floor layout, turned upright for portrait. They are static previews to compare options, not working builds.

01

Wayfinder

Google Maps-style From → To route card. The smallest step from today's design; closest to the existing blue and white.
02

Midnight

Premium dark glass with a glowing route, quick-access tiles and a three-step flow with progress dots.
03

Guided

A full-screen wizard that asks one question per screen and ends with a review step. Fixes workflow confusion most directly.
04

Campus

Destination first, with categories, room cards and place details. Asks where you are inside the directions sheet.
05

Field Pro

A Navigate / Research mode switch, a sensor readiness strip, a diagnostics heads-up display and a survey table. Built for field testing.

Issues seen in the current build (emulator, C-F4)

  • The wide floor plan fills only about a quarter of a portrait screen; most of the space is empty blue.
  • Room names appear twice: tiny labels drawn into the plan image, plus large floating chips that cover the plan and each other.
  • Start, destination and direction live in separate sheets with different entry points ("Set start", search, "Choose destination"), so it's easy to miss a step.
  • The Explore tab shows the Buildings screen when no floor is open. The import dialog defaults to "replace everything", with a red warning.
  • Tools mixes the user journey (map → survey → navigate) with research utilities. Research views open three levels deep through dialogs.
  • The wording is technical ("fresh Wi-Fi fix", "reference point", "Real device · venue"), and status lines repeat across the card.

You can mix and match. For example, Guided's flow logic and Field Pro's Research switch work with any visual style.
